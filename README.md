
# Aurévia – Skincare Product E-Commerce Website

Aurévia - built with HTML, CSS, JavaScript, PHP and MySQL. 

It's an online platform for skincare products. Users can shop and enjoy a seamless skincare experience ANYTIME ANYWHERE through a simple, modern and responsive interface.

This is a project which allows users to: 
- Join us to become one of our valuable members
- Browse Skincare Products
- Search Specific Skincare Products
- Add Items To Their Cart
- View their Orders In Cart
- Complete Purchases  
- Make Payment 
- Contact Us
- Edit Profile
  

Backend Database also included for users, products and orders management via phpMyAdmin.

 
## Getting Started
###  Dependencies
Make sure you have the following installed before running the project:

#### Backend Dependencies 
- WAMP Server - Apache, PHP, MySQL [*Download Link:* http://www.wampserver.com/en/]
- phpMyAdmin (included in WAMP Server) - Database Management
- PHP - Version 8.3.14
- MySQL - Version 9.1.0
- Web Browser(Chrome, Microsoft Edge)

#### Frontend Dependencies 
- Google Fonts - Typography
- Font Awesome - Icons
- Javascript(AJAX) - Asynchronous Request




## Installation & Execution

    1. Download Project
        - Download the UECS2194_Assignment_P4_G10.zip
        - Extract it into 'www' folder of your WAMP Installation
        - Example: C:/wamp64/www/assignment
    
    2. Open and start the Wamp Server

    3. Databse Setup
        a. Open phpMyAdmin(Link: http://localhost/phpmyadmin/)
            - username: root
            - password: "" (Leave it Empty)
            - Server Choice: MySQL
        b. Import db.sql in UECS2194_Assignment_P4_G10 folder into phpMyAdmin

    4. Program Execution
        - Open your browser and go to localhost(PORT NUMBER)/foldername/pagename
        - Example: localhost8081/UECS2194_Assignment_P4_G10/index.php

 
    
## Help
If the website does not loads or runs, make sure:

- WAMP server is running (Green Icon In Taskbar).  
- Project folder is correctly placed in the `www` directory.  
- Database is imported in phpMyAdmin.
- Path to the web is correctly type (Port Number, Folder Name, Page name all correctly type)
